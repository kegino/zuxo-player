# Zuxo Player — Website Oficial

Reprodutor e plataforma de streaming IPTV de alta performance em 4K sem travamentos.

- **Domínio oficial:** [zuxoplayer.website](https://zuxoplayer.website)
- **Palavra-chave principal:** Zuxo Player
- **Tecnologias:** TanStack Start, React 19, Vite, Tailwind CSS, TypeScript.

## Funcionalidades e Otimizações

- Hero cinematográfico com imagem em formato WebP otimizada para dispositivos móveis e desktop.
- Paleta visual baseada no tema escuro cósmico com contraste aprimorado (Cyan Neon + Quantum Amber) para máxima legibilidade de botões e CTAs.
- Integração direta com WhatsApp para suporte e liberação imediata de teste grátis e planos.
- 11 artigos originais e aprofundados no Blog com foco em SEO, Schema.org (BlogPosting, FAQPage, Product, BreadcrumbList), EPG e tutoriais.
- Geração automática de `sitemap.xml` e `rss.xml`.

## Desenvolvimento Local

```sh
pnpm install
pnpm dev
```

## Build de Produção

```sh
pnpm build
```
